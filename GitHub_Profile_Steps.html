GitHub Profile README: Step-by-Step Guide

This page is designed to be printable. Open it in a browser and use Print → Save as PDF to create a PDF copy with active links.

1. Learn the basics you need

Before making a profile README, study the essentials:

  • Markdown Guide – headings, lists, links, images, tables, code blocks
  • GitHub Profile README Docs – how GitHub displays your profile README
  • HTML basics – helpful for layout and sections
  • MDN HTML basics – learn structure and formatting

2. Create a special GitHub repository

  1. Go to GitHub New Repository.
  2. Create a repository with the exact same name as your GitHub username.
  3. Example: if your username is sivag-og, create a repo named sivag-og.
  4. Make it public.
  5. Add a file called README.md.

3. Write a strong profile README

Use sections such as:

  • Hi / Intro
  • About Me
  • Current Role
  • Skills / Tech Stack
  • Interests
  • Career Goal
  • Contact / Social Links

4. Add profile-friendly content

Include:

  • Short and clear intro
  • Current job and location
  • Career direction
  • Technologies you use
  • Projects or learning focus
  • Links to LinkedIn, portfolio, email, or social profile

5. Add badges and tech icons

Use these resources to make your profile look professional:

  • Shields.io – for badges
  • GitHub Readme Stats – GitHub stats cards
  • Simple Icons – brand icons
  • Devicon – programming language icons

6. Use a simple profile template

Example:

# Hi, I'm Sivamoorthy Govindaraj 👋

## About Me
I am a DevOps Engineer at Gainwell Technologies, Chennai, and I am aspiring to become a Full Stack Developer.

## Interests
- DevOps
- CI/CD
- Cloud
- Full Stack Development
- AI-powered automation

## Tech Stack
![Linux](https://img.shields.io/badge/Linux-FCC624?style=for-the-badge&logo=linux&logoColor=black)
![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white)

## Connect
- LinkedIn: your-link
- Email: your-email

7. Publish the README

  1. Commit the file.
  2. Push it to GitHub.
  3. Go to your profile page to see the result.
  4. Keep improving the design over time.

8. Good places to study examples

  • Microsoft GitHub profile
  • GitHub profile
  • Search GitHub for profile README examples

9. Recommended learning order

  1. Markdown
  2. GitHub profile README structure
  3. Simple HTML for styling
  4. Badges and GitHub stats widgets
  5. Review and improve with examples
Tip: For a polished GitHub profile, start simple and improve gradually. A clean profile is better than a crowded one.
